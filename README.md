# EcoWatch — ドローン環境モニタリング共創エリア探索

環境調査・自然観測を目的とするドローン**飛行計画（申請ベース）**の分布を全国地図上で可視化し、
環境分野での共創（自治体・研究機関・自社環境部門）の候補エリアを探索するための静的 Web アプリです。

国土交通省 Project LINKS『無人航空機飛行計画データ（2025年度）』の全12ヶ月・約297万件を走査し、
飛行目的に「環境調査」または「自然観測」を含む約39万件を抽出。出発地（行政区域の代表地点）ごとに
集計して、市区町村集計（比例円）とヒートマップで表示します。

## 主な機能

- **市区町村集計マップ**：出発地ごとの環境用途飛行計画件数を、比例円（大きさ・色）で表示。
- **ヒートマップ**：環境用途飛行の密度を全国スケールで俯瞰。
- **フィルタ**：飛行目的（環境調査／自然観測）、対象期間（月次レンジ）、包括申請の除外。
- **背景地図**：地理院タイル（標準／淡色／衛星写真）。地形陰影の重ね合わせ。
- **凡例・出典・データ品質に関する注記**を常時表示。

## データの取り扱いと注記

本マップは以下を前提とします（UI 上にも明記）。

- **申請・報告ベース**であり、実際の飛行・実態を示すものではありません（「飛行計画」）。
- 元データは紙資料のスキャンから LINKS Veda により抽出されており、**完全性・正確性は保証されません**。
- 出発地は**行政区域の代表地点に秘匿化**されています。本サイトは個人特定につながる二次加工を行いません。
- 飛行目的フラグが極端に多い行（業務目的を10件以上選択）は**包括申請**とみなし、既定で除外しています
  （用途を絞った分析のため）。「包括申請を除外」のチェックを外すと集計に含められます。
- 時系列は「ファイル＝対象月」を信頼単位とし、月別に集計しています。

## ディレクトリ構成

```
docs/                 GitHub Pages で配信する静的サイト（公開ルート）
  index.html
  css/style.css
  js/app.js
  data/
    summary.json        サマリ（総件数・月別・目的別など）
    municipalities.json 出発地（市区町村）別の月×カテゴリ集計
  vendor/             MapLibre GL JS / グリフ（CDN 非依存で自己完結）
scripts/
  extract_env_flights.py  月次GeoJSON（約10GB）をストリーム処理し環境用途を抽出
  build_site_data.py      抽出結果から配信用の軽量JSONを生成
```

## データの再生成手順

```bash
pip install ijson openpyxl

# 1) 全12ヶ月（16ファイル・約10GB）をダウンロード→ストリーム抽出（逐次削除）
#    出力: data/env_flights.json（環境用途 約39万件）
python3 scripts/extract_env_flights.py data

# 2) 配信用の軽量データを生成（docs/data/ に出力）
python3 scripts/build_site_data.py data/env_flights.json docs/data
```

`data/` は中間生成物のためコミットしません（`.gitignore`）。配信に必要な `docs/data/*.json` のみをコミットします。

## ローカル確認

```bash
cd docs && python3 -m http.server 8099
# http://127.0.0.1:8099/ を開く
```

## デプロイ（GitHub Pages）

`.github/workflows/deploy-pages.yml` により、`docs/` を GitHub Pages へ自動デプロイします。
リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定してください。
API キー不要・静的タイルのみで動作し、Pages 単独で完結します。

## 抽出データの傾向（参考）

- 走査 2,971,260 件 → 環境用途（環境調査・自然観測）387,100 件を抽出（うち包括申請 94,958 件）。
- 環境用途の飛行計画は出発地で見ると一部地域に強く集中する傾向があり、
  共創候補エリアの一次スクリーニングに活用できます。

## 今後の拡張（要確認）

- **自然環境レイヤとの重ね合わせ**：国土数値情報（河川・森林地域・自然公園）、環境省データを
  トグルレイヤとして追加し、環境用途飛行と自然環境域との空間的な重なりを可視化。
